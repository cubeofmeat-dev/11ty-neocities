# 11ty-Neocities Project Instructions

## Project Overview
Personal website built with **Eleventy (11ty)** for Neocities hosting. Contains game reviews organized by month/year, manga reviews, and a main homepage.

## Project Structure

### Source Files (`src/`)
- **games.html** - Main games listing page
- **manga.html** - Main manga listing page
- **index.html** - Homepage
- **index.css** - Main stylesheet
- **games/** - Monthly game review markdown files and configurations
- **manga/** - Manga review markdown files
- **_includes/** - Layout templates for rendering pages

### Layouts (`src/_includes/`)
- `months-layout.html` - Template for monthly game review pages
- `manga-post-layout.html` - Template for individual manga reviews
- `games-layout.html` - Games listing layout
- `manga-layout.html` - Manga listing layout
- `index-layout.html` - Homepage layout

### Output (`_site/`)
- Generated static HTML files mirroring src/ structure
- Images directory copied from src/images/

## Monthly Game Reviews - File Naming & Structure

### Naming Pattern
**Files:** `YYYY-MM.md` (e.g., `2026-05.md` for May 2026)
**Location:** `src/games/`

### Front Matter Template
```yaml
---
title: [Month Name]
layout: months-layout.html
tags: games
year: YYYY
month: MM (month number - currently 0-indexed in example files)
---
```

### File Examples
- `2026-04.md` - April 2026 (ULTRAKILL review)
- `2026-05.md` - May 2026 (currently boilerplate)
- `2026-03.md`, `2026-02.md`, etc.

### Content Structure
Each monthly review follows this pattern:
1. Game title as H1 (`# GAME TITLE`)
2. Review status line: `_Review In Progress_` or similar
3. Date: `_Month Date, Year_`
4. Game logo image: `<img class="img-logo snes-container no-padding" src="/images/game-logo.png">`
5. Quote/tagline in italics
6. Review paragraphs (typically 3-5)
7. Grade as H2: `## [A/B/C/D/F/S/1/2/3]`
8. Game screenshots in HTML block

### Grade System & Color Mapping
Grades are mapped to SNES-styled colors via `gameFormat` filter:
- **S** → sunshine-underline, text-sunshine-color
- **A** → ocean-underline, text-ocean-color
- **B** → nature-underline, text-nature-color
- **C** → turquoise-underline, text-turquoise-color
- **D** → ember-underline, text-ember-color
- **F** → plumber-underline, text-plumber-color
- **1/2/3** → galaxy/phantom/rose colors (bonus grades)

## Build & Development

### Commands
- `npm start` - Start dev server with live reload
- `npm build` - Generate static site to `_site/`

### Config
- **Input:** `src/`
- **Output:** `_site/`
- **Includes:** `src/_includes/`
- **Passthrough Copy:** `src/index.css`, `src/images/`

## Key Files
- `eleventy.config.js` - 11ty configuration with gameFormat filter
- `package.json` - Dependencies (11ty, markdown-it)
- `README.md` - Project documentation

## Common Tasks

### Creating a New Monthly Game Review
1. Create `src/games/YYYY-MM.md` with template front matter
2. Set `year` to YYYY and `month` to MM
3. Title should be the month name (January, February, etc.)
4. Follow content structure: title → status → date → logo → quote → content → grade → images

### Adding Game Images
Place images in `src/images/` and reference as `/images/filename.png`

### Month to File Mapping Examples
- January 2026 = `2026-01.md`
- February 2026 = `2026-02.md`
- May 2026 = `2026-05.md`
- December 2026 = `2026-12.md`
